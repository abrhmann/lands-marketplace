# Alwaha Outlet Landing Page

واجهة متجر عربية (RTL) باسم **Alwaha Outlet** مستوحاة من فكرة متاجر الأوتلت، مع تصميم حديث وتركيز على الأداء.

## التشغيل محليًا

```bash
python3 -m http.server 4173
```

ثم افتح:

http://localhost:4173

## المزايا

- لغة عربية كلغة رئيسية مع اتجاه RTL.
- تصميم متجاوب للجوال والتابلت وسطح المكتب.
- بنية خفيفة (HTML/CSS/JS فقط) لسرعة التحميل.
- بطاقات منتجات ديناميكية قابلة للربط لاحقًا مع API أو منصة تجارة إلكترونية.
